# The Daily World — 24 November 2026

An original 1024×1024 newspaper front page that sums up the world's news of Tuesday 24 November 2026 in a single image. Headlines were pulled live from the BBC News RSS feeds and filtered to items published on 24 November 2026, then laid out as a dark masthead, a lead story, and a two-column grid of region-tagged headline cards. `entry.png` is the artwork; `main.ts` copies it into the make.fun output directory at run time.
